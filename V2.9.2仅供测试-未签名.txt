V2.9.2 国内网络增强版——未签名测试包说明

本压缩包仅用于受控测试，EXE 尚未购买并应用正式 Authenticode 代码签名，不能作为面向普通用户公开发布的正式版。

使用前：
1. 完整解压整个压缩包，不要直接在微信、QQ 或压缩软件预览窗口中运行 EXE。
2. 核对 SHA256SUMS 中的 EXE、offline/manifest.json、SBOM.cdx.json 哈希。
3. 确认窗口标题和左侧版本标签显示 V2.9.2。
4. API Key 只输入测试者自己的 DeepSeek Key，不要截图或转发。

本版重点测试：
- 全新 Windows 10/11 x64、没有 Claude Code、Node/npm、Python 3.12、VS Code 的电脑。
- 中国电信、联通、移动、校园网和单位代理环境的安装来源切换。
- 安装成功后的桌面快捷方式、更新检查和完整卸载。
- 卸载后对比安装前快照，确认仅删除配置器新增内容，并保留安装前已有软件与用户数据。

已知边界：
- 包内不直接再分发 Claude Code 二进制；完全断网且电脑原本没有 Claude Code 时无法完成 Claude Code 本体安装。
- 企业应用控制、杀毒软件拦截、TLS 检查代理和区域网络封锁仍可能需要管理员处理。
- 正式发布前仍需完成干净虚拟机全流程验收、代码签名和正式 HTTPS 更新清单配置。
